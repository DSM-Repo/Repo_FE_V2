# Repo-V2

Repo-V2는 대덕소프트마이스터고등학교 학생을 위한 이력서/포트폴리오 관리 플랫폼입니다.

## Frontend Base

- Package Manager: `pnpm`
- Framework: Next.js App Router
- Runtime: React
- Language: TypeScript
- Lint: ESLint

## Local Run

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm lint
pnpm build
```

## Docs

작업 전 `docs/index.md`를 기준으로 제품 방향, 요구사항, 프론트엔드 구조, 기술 스택 문서를 확인합니다.
