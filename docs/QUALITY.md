# Quality Guide

Repo-V2의 품질 기준을 정리합니다.

## 제품 품질

- 학생이 실제 취업에 활용 가능한 포트폴리오를 만들 수 있어야 한다.
- 선생님이 학생 상태를 빠르게 파악하고 피드백할 수 있어야 한다.
- 학교가 레주메북을 안정적으로 생성/관리할 수 있어야 한다.

## 코드 품질

- feature 단위 경계를 유지한다.
- shared layer에는 여러 feature에서 실제로 재사용하는 것만 둔다.
- 불필요한 추상화를 피한다.
- 아직 결정되지 않은 editor/PDF/state/form 계열 라이브러리에 과도하게 종속된 문서를 작성하지 않는다.

## 문서 품질

- 확정된 사실과 미결정 사항을 구분한다.
- TODO/Open Question을 숨기지 않는다.
- 중요한 결정은 `DECISIONS.md`에 남긴다.

## 데이터 안정성

특히 다음 데이터는 저장/복원 안정성이 중요합니다.

- 문서형 포트폴리오 본문
- 이미지/링크 첨부
- 피드백 위치
- 공개 상태
- 제출 상태
- PDF 변환 결과

## 보안/권한 품질

- 프론트 route guard는 UX 보조 장치다.
- 실제 권한 검증은 백엔드 API에서 수행해야 한다.
- 학생/선생님 모두 변경 가능한 공개 상태 정책은 감사 가능성을 검토해야 한다.

## 레거시 참고 기준

유지할 가치:

- 학교가 학생 이력서를 한 번에 모아 레주메북으로 만들 수 있음
- 내부 도서관에서 레주메북을 확인할 수 있음
- PDF Viewer의 빠른 이동 등 열람 편의 기능

버릴 방식:

- 정해진 input form에 입력하면 모두 같은 디자인으로 출력되는 구조
- 레거시 앱 분리 구조를 무비판적으로 복제하는 것
