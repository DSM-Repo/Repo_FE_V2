# Execution Plans

이 디렉터리는 실제 구현 전에 기능 단위 실행 계획을 저장하는 곳입니다.

## 작성 시점

- 요구사항이 충분히 정리된 뒤
- 구현 범위가 명확해진 뒤
- 필요한 API/디자인/테스트 기준을 확인한 뒤

## 파일명 규칙

```txt
001-project-harness.md
002-auth-routing.md
003-resume-editor.md
004-pdf-conversion.md
005-teacher-dashboard.md
006-feedback-mode.md
007-library.md
```

번호와 이름은 실제 우선순위에 맞춰 조정할 수 있습니다.

## 문서 템플릿

```md
# 실행 계획 제목

## 목표

## 범위

## 비범위

## 관련 문서

## 필요한 API / 데이터

## UI/UX 참고

## 구현 단계

## 테스트 기준

## Open Questions
```

## 초기 후보

- 프로젝트 하네스 정리
- 인증/권한별 라우팅
- 문서형 포트폴리오 에디터
- PDF 변환
- 선생님 대시보드
- 피드백 모드
- 내부 도서관
