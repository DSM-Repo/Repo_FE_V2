# Publishing Guide

Figma 디자인을 실제 화면으로 옮길 때의 기준 문서입니다. 아직 세부 퍼블리싱 계획은 확정하지 않습니다.

## 기본 원칙

- Figma를 기준으로 하되, 구현 안정성과 재사용성을 함께 고려한다.
- 공통 컴포넌트로 추출할 수 있는 UI는 반복 구현하지 않는다.
- 픽셀 단위 완벽함보다 제품 흐름과 유지보수성을 함께 본다.
- 문서형 에디터와 PDF Viewer는 일반 페이지보다 별도 검증 기준이 필요하다.

## 우선순위

1. 공통 레이아웃
2. 인증/권한별 진입 흐름
3. 학생 포트폴리오 작성 화면
4. 선생님 학생 관리/피드백 화면
5. 도서관/PDF Viewer 화면
6. 세부 인터랙션/애니메이션

## 접근성 기준

- 버튼과 입력 요소는 키보드 접근을 고려한다.
- 상태 태그는 색상만으로 의미를 전달하지 않는다.
- 모달/사이드바는 focus trap과 닫기 동작을 고려한다.
