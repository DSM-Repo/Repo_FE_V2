# UI/UX Direction

## 핵심 방향

Repo-V2의 UI/UX 핵심은 학생이 실제 취업에도 쓰고 싶은 포트폴리오 작성 경험을 제공하는 것입니다.

## 참고 자료

- UI 참고 영상: https://www.youtube.com/watch?v=fR8tsJ2r7Eg

참고 영상은 화면 구성과 컴포넌트 완성도 논의에 활용하되, Repo-V2의 핵심 가치와 Figma 디자인을 우선합니다.

## 학생 경험

기존의 input form 중심 작성 경험에서 벗어나 문서 작성 경험에 가까워져야 합니다.

중요한 기준:

- 글을 쓰는 느낌이 자연스러울 것
- 텍스트 스타일, 이미지, 링크, 인용을 쉽게 사용할 수 있을 것
- 필수 상단 정보는 명확하고 빠르게 입력할 수 있을 것
- 본문은 학생의 개성을 드러낼 수 있을 것
- PDF로 변환했을 때 결과가 안정적일 것

## 선생님 경험

선생님 화면은 관리 대시보드 성격이 강합니다.

중요한 기준:

- 학생 목록을 빠르게 찾을 수 있을 것
- 제출완료/미제출 상태가 한눈에 보일 것
- 피드백 모드 진입이 쉬울 것
- 피드백 추가/수정/삭제 흐름이 짧을 것
- 전공/반 기준 탐색이 쉬울 것

## 도서관 경험

내부 도서관은 기존 레주메북 열람 가치를 유지하면서 탐색성을 개선해야 합니다.

중요한 기준:

- 레주메북 목록을 쉽게 탐색
- PDF Viewer 열람
- 반별/학생별 빠른 이동
- 전공/반 필터
- 이름 검색

## 이번 단계에서 하지 않을 것

- Figma 화면별 세부 퍼블리싱 계획 확정
- 외부 기업용 웹 뷰어 UX 고도화
- 완전 자유형 웹사이트 빌더 수준의 커스터마이징
- 모바일/태블릿 세부 최적화

## 1차 퍼블리싱 화면 기준

- 웹 데스크톱 기준으로 진행합니다.
- 기준 범위는 `1440 × 900`부터 `1920 × 1080`까지입니다.
- `1440 × 900`에서 핵심 레이아웃이 가장 안정적으로 보이는 것을 우선합니다.
- `1920 × 1080`에서는 콘텐츠 max-width와 여백 설계로 과도한 확장을 방지합니다.
- 도서관 레주메북 상세처럼 한 화면 안에서 열람하는 화면은 화면 높이가 커질 때 아래 여백만 늘리지 않고, 툴바·문서·페이지 표시 묶음 전체를 세로 기준으로 균형 있게 배치합니다.
