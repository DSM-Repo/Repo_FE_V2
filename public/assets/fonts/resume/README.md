# Resume font

Pretendard Variable v1.3.9, self-hosted so resume wrapping uses the same font on Windows and macOS.

Source: https://github.com/orioncactus/pretendard/tree/v1.3.9
Asset: packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2
License: SIL Open Font License 1.1 (see OFL.txt).

The `Repo Resume Pretendard` CSS family is scoped to the fixed-size resume document. Keep the font available before accepting edits so pagination measures the final glyph metrics.
